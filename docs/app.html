STAR · Steam Timed Achievement Replayer

Replay a real player's achievement timeline

Turn a SteamHunters export into realistic sessions and breaks, then let ArchiSteamFarm unlock them on your account at the same pace.

Schedules are made right here in your browser.

Get the app

Running games needs the app on your Mac or Linux PC. One line installs it, ArchiSteamFarm and its achievement plugin:

curl -fsSL https://raw.githubusercontent.com/sepehrsardooeinasab/star/main/install.sh | sh

Paste it into Terminal. Needs Python 3, which macOS offers to install the first time if it's missing.

  1. Open STAR. It walks you through installing ArchiSteamFarm and signing in to Steam.
  2. On SteamHunters, open a player's achievements for the game, select the whole list and copy it.
  3. Press New schedule, paste it, enter the game name and App ID under Settings, and save.
  4. Open Runs in the top bar and press Run. It keeps going when you close the window.

Run the same command again any time to update; your games and settings are kept.

Achievements

Input
How to edit
  • Click a delay_s value to change it (in seconds). On a gap row, that's the gap's length.
  • + after a session number starts a new session at that achievement; − after a gap label removes the gap.
  • Edited values are highlighted; ↺ or clicking + / − again undoes them.
Output
Options

A pause in the player's unlocks longer than "Session break after" starts a new session; between sessions the game is closed, as if the player stopped playing.

A link
  • A link to the player's achievements for a game, from SteamHunters or Steam: steamhunters.com/id/name/apps/appid/achievements steamcommunity.com/id/name/stats/appid/achievements
  • With this method, the player's Steam profile must be public.
Or the page
What to paste
  • On SteamHunters, open the player's achievements for a game.
  • Select the whole page (⌘A / Ctrl+A), copy it and paste it here.
  • Any sort or grouping works.
  • Achievements the player hasn't unlocked are skipped.
  • Steam's own page can't be pasted; use its link.
What each setting does
  • Game name: the game's name as it shows in Runs, like Counter-Strike 2. Fills itself in from a link or a pasted page.
  • App ID: the number in the game's store URL (store.steampowered.com/app/730).
  • Copied from: optional note of whose profile the export came from. Doesn't change the schedule.
  • Session break after: a pause in the export longer than this starts a new session. Between sessions the game is closed.
  • Max session length: an unlock that would run a session past this starts a new one.
  • Warn if break under: only shows a notice for shorter breaks, so you can stretch them on the Timeline tab.

Times are in hours. Changes re-split the sessions right away.

Why sessions

A session is one sitting: the game shows as running on your Steam profile, the achievements unlock at the player's pace, then the game closes for a break. Splitting the unlocks into sessions like the player's own means your playtime grows along with them, with breaks in between, the way a real playthrough looks. Unlocks that all land at once, or with no time spent in the game, look automated.
