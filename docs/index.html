Steam achievement scheduler

Replay a real player's achievement timeline

Turn a SteamHunters export into realistic sessions and breaks, then let ArchiSteamFarm unlock them on your account at the same pace.

Schedules are made right here in your browser.

Get the app

Running games needs the app on your Mac or Linux PC. One line installs it, ArchiSteamFarm and its achievement plugin:

curl -fsSL https://raw.githubusercontent.com/sepehrsardooeinasab/steam-auto-unlocker/main/install.sh | sh

Paste it into Terminal. Needs Python 3, which macOS offers to install the first time if it's missing.

Finish setting up
  1. ArchiSteamFarm

    Downloads ArchiSteamFarm and its achievement plugin (about 50 MB).

  2. Steam account

    Sign in with the account to unlock achievements on. It's saved only in ArchiSteamFarm's own config on this computer.

How to edit
  • Click a delay_s value to change it (in seconds). On a gap row, that's the gap's length.
  • + after a session number starts a new session at that achievement; − after a gap label removes the gap.
  • Edited values are highlighted; ↺ or clicking + / − again undoes them.
Output
What each setting does
  • Game name: names the files and is what you pass to runsteamunlocker <name>. Saved in lowercase.
  • App ID: the number in the game's store URL (store.steampowered.com/app/730).
  • Copied from: optional note of whose profile the export came from. Doesn't change the schedule.
  • Session break after: a pause in the export longer than this starts a new session. Between sessions the game is closed.
  • Max session length: an unlock that would run a session past this starts a new one.
  • Warn if break under: only shows a notice for shorter breaks, so you can stretch them on the Timeline tab.

Times are in hours. Changes re-split the sessions right away.
